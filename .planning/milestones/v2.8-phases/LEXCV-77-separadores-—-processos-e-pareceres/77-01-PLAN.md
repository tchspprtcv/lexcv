<design_decision_locked>
Lazy fetch é obtido via SUB-COMPONENT MOUNT APPROACH (decisão bloqueante resolvida em 77-PATTERNS.md — NÃO tocar em hooks). Nenhum dos hooks (`useProcessos`, `usePareceres`) aceita um override `enabled` externo hoje, e NÃO devem ser alterados. Em vez disso, criam-se dois componentes locais que chamam o hook internamente e só são montados dentro do ramo `tab === "processos"` / `tab === "pareceres"`. Como a renderização condicional JSX (`tab === "processos" ? <ClienteProcessosTab .../> : ...`) só monta o componente quando o ramo está ativo, React só invoca os hooks (e dispara as queries) nesse momento — fetch lazy verdadeiro, zero alterações nos ficheiros de hooks. Este é exatamente o idioma já usado neste ficheiro para `ClienteContactosCard`/`ClienteNotasCard`, tornado condicional.
</design_decision_locked>
