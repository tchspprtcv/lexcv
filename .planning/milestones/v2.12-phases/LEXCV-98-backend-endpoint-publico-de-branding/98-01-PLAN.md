<objective>
Criar um endpoint público não-autenticado `GET /api/v1/public/branding` que devolve exclusivamente `nome` e `logoDataUrl` da tenant singleton, através de uma DTO explícita de cópia campo-a-campo (`TenantPublicInfoResponse`) — nunca a entidade `Tenant` — e registá-lo na allowlist do `SecurityConfig` como uma entrada literal exacta.

Purpose: A app `webpage/` (Phase 99) precisa de obter o nome/logo da instituição para personalizar a landing page pública sem qualquer sessão autenticada. Este é o único bloqueio de dados real dessa fase; até existir, a `webpage/` consome um stub fixo.

Output: Novo `PublicController` + novo DTO `TenantPublicInfoResponse` + um método derived-query em `TenantRepository` + uma linha exact-literal na allowlist do `SecurityConfig` + um teste Mockito que prova o comportamento 404/200. Fase puramente aditiva — nenhum código de segurança ou endpoint existente é alterado.

Cobre: LP-01 (endpoint público via DTO, apenas nome+logoDataUrl) e LP-02 (allowlist entry exact-literal, nunca wildcard).
</objective>
