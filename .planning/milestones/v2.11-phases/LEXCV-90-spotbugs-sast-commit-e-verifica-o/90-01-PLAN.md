| Boundary | Description |
|----------|-------------|
| client → REST API (@RequestBody) | Untrusted JSON is deserialized directly into JPA @Entity parameters at controller create endpoints; a crafted `id` field crosses here. |
| internal object → caller (getter/record accessor) | Mutable internal collections (authorities set, record list fields) escape to callers who could mutate shared state. |
| Maven Central → build (plugin resolution) | SpotBugs/FindSecBugs plugin artifacts are pulled at build time. |
