Backend also builds the entity from an explicit allowlist and forces status server-side, so injected forbidden fields are ignored. |
| T-66-SC | Tampering | npm/pnpm installs | accept | No new dependencies added this phase (v2.6 research: existing stack covers 100%). No install tasks; no legitimacy gate needed. |
