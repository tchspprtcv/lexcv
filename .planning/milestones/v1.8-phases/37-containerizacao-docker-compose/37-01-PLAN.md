  <action>
Create backend/Dockerfile as a two-stage build:

Stage 1 (builder) — base image: maven:3.9-eclipse-temurin-23
- WORKDIR /build
- COPY pom.xml .
- RUN mvn dependency:go-offline -q  (cache deps layer before copying source)
- COPY src ./src
- RUN mvn -DskipTests package -q
- The resulting JAR is in target/*.jar

Stage 2 (runtime) — base image: eclipse-temurin:23-jre-alpine
- WORKDIR /app
- RUN addgroup -S appgroup && adduser -S appuser -G appgroup  (non-root user)
- COPY --from=builder /build/target/*.jar app.jar
- RUN mkdir -p /app/uploads && chown appuser:appgroup /app/uploads
- USER appuser
- EXPOSE 8080
- ENTRYPOINT ["java", "-jar", "app.jar"]

Do NOT bake any env vars into the image. All env vars (SERVER_PORT, DB_HOST, DB_PASSWORD, JWT_SECRET, etc.) are injected at container runtime via Docker Compose.

Create backend/.dockerignore with the following exclusions:
- target/
- .env
- .env.*
- *.md
- .git/
- .gitignore
- .mvn/
  </action>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Host → Docker build context | .dockerignore gates what enters the image; leaked .env files expose secrets |
| Image layers → runtime | Secrets baked into ENV instructions persist in image history |
| Container process → filesystem | Running as root inside container elevates blast radius of RCE |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-37-01 | Information Disclosure | backend/Dockerfile ENV layer | mitigate | No ENV instructions with secret values; all secrets injected at runtime via compose --env-file |
| T-37-02 | Elevation of Privilege | Container running as root | mitigate | Non-root user created in both Dockerfiles (adduser appuser); USER instruction before ENTRYPOINT |
| T-37-03 | Information Disclosure | .env files in build context | mitigate | .dockerignore excludes .env and .env.* in both apps |
| T-37-SC | Tampering | maven:3.9-eclipse-temurin-23 / node:22-alpine base images | accept | Official images from Docker Hub; pinned to major.minor tags; no --no-verify bypass |
</threat_model>
