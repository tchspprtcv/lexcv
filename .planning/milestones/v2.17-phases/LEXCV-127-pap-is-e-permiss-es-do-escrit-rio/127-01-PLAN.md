<objective>
Close inherited debt 2a (127-CONTEXT.md Decisão 2a) so that PAPEL-04 (renaming) can ship without
silently breaking Pareceres.

`ParecerController:423` and `:494` gate "who may deliver a parecer" and "who may create a version"
with `principal.getRoles().contains("ADMIN")`. Those two sites work today only because
`TenantRole.nome` is a literal copy of the molde name. The moment an office renames its
administrator role, both checks stop matching and the office loses the ability to deliver pareceres,
with no error message that explains why.

Phase 126 could not convert these two sites: `ResolucaoPapeisService.temPapelDeMolde(User, String)`
needs a loaded `User`, and these two sites only have the `UserPrincipal` from the security context
(127-PATTERNS.md §2). Loading the `User` again would add a second per-request query, which is
exactly what `JwtAuthenticationFilter:50-58` is written to forbid. So the principal must start
carrying molde provenance, resolved once, in the same place `roles`/`permissions` already are.

Purpose: renaming becomes safe before renaming ships. This plan lands before any endpoint in this
phase allows a rename.
Output: `UserPrincipal.moldeIds`, `ResolucaoPapeisService.resolverMoldeIds`, a
`temPapelDeMolde(UserPrincipal, …)` overload, both `ParecerController` sites converted, and a
behavioural test proving a renamed office ADMIN role still passes.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| JWT cookie → `JwtAuthenticationFilter` | an authenticated but untrusted caller's identity is re-resolved from the database on every request; everything downstream reads the resulting `UserPrincipal` |
| `UserPrincipal` → `ParecerController` business guards | the principal is the only authority input at lines 423/494; a principal that misstates provenance silently changes who may finalise a parecer |

| T-127-01 | Elevation of Privilege | `ResolucaoPapeisService.resolverMoldeIds` office branch | mitigate | skip null `moldeId` so a role an office invented can never claim provenance of any molde; assert this in `ResolucaoPapeisServiceTest` |
