</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Cliente autenticado (ADMIN) → `POST /api/v1/admin/users` | O corpo do pedido é input não confiável; qualquer campo nele pode ser forjado |

| Regra de negócio ↔ persistência | A verificação corre em memória antes do `save()`; não existe constraint de base de dados a garanti-la |
