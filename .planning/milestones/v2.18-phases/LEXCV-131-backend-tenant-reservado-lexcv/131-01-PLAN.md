# Phase 131 Plan 01: Backend — Tenant Reservado LexCV

**Goal:** O tenant reservado da plataforma passa a chamar-se "LexCV" em todo o código backend, com
uma migração SQL documentada para bases de dados já provisionadas.

**Requirements:** BACK-01, BACK-02

## Tasks

1. Substituir "ALCv" → "LexCV" (case-sensitive) em `AuthController.java`,
   `PlatformAdminController.java` (incl. `TENANT_RESERVADO`), `PublicController.java`,
   `Tenant.java`, `TenantRepository.java`, `DatabaseSeeder.java`,
   `MigracaoPapeisEscritorioService.java` (incl. `TENANT_RESERVADO`)
2. Substituir "ALCv" → "LexCV" nos 6 ficheiros de teste associados, incluindo o nome do método
   `migrar_tenantReservadaALCv_...` → `migrar_tenantReservadaLexCV_...`
3. Criar `backend/migrations/131-rename-tenant-reservado-lexcv.sql`
   (`UPDATE t_tenant SET nome = 'LexCV' WHERE nome = 'ALCv'`)
4. Adicionar entrada em `backend/migrations/README.md` (Path A skip list, tabela Path B linha 18,
   tabela de re-run safety, secção "Known execution status")
5. Registar a nova migração pendente em `.planning/STATE.md` (Pending Todos)
6. `mvn test` limpo (ambiente sem JDK 23 — corrido com `-Dmaven.compiler.release=21` só na linha
   de comando, `pom.xml` inalterado)
7. `mvn spotbugs:check` limpo
