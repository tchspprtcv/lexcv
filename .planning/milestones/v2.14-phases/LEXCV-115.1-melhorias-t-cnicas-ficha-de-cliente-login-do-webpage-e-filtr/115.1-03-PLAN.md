Área 3 — Alinhar o padrão visual dos filtros de Pareceres com Processos/Clientes.

Buttons keep their text — icon-only conversion is explicitly out of scope (locked by Phase 115's own 115-CONTEXT.md, reaffirmed here).

Purpose: Closes reported gap #3 — visual inconsistency of the Pareceres filters vs the rest of the app.
Output: 1 modified file; ~6 Select→NativeSelect conversions + 3 input + several label conversions; Radix Select import removed.
</objective>
