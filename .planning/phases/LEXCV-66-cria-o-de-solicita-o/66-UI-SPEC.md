## Spacing Scale

Identical to Phase 65 — reused verbatim for module consistency:

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline badge padding |
| sm | 8px | Compact element spacing (label-to-input gap via `space-y-2`) |
| md | 16px | Default element spacing (form field row gaps via `space-y-4`, grid `gap-4`) |
| lg | 24px | Section padding (page header to content gap, root `space-y-6`) |
| xl | 32px | Layout gaps (between major page sections, not typically needed — this is a single-card form) |
| 2xl | 48px | Major section breaks (not used — form fits in one Card) |
| 3xl | 64px | Page-level spacing (not used) |

Exceptions: none. Root page wrapper uses `space-y-6` (24px); form field groups use `space-y-2` (8px) internally and `space-y-4` (16px) between rows — matches `processos/novo/page.tsx` exactly.

## Typography

Identical to Phase 65 — reused verbatim:

| Role | Size | Weight | Line Height |

| Body / Label | 14px (text-sm) / 12px (text-xs) | 400 (regular) | 1.5 (body) / 1.4 (label) |

## Color

Identical palette to Phase 65 — reused verbatim, no new colors introduced:

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | white / `dark:bg-[#020617]`-equivalent page background | Page background, Card surface, input backgrounds |
| Secondary (30%) | `slate-50`/`slate-100` (light) — `slate-900`/`slate-800` (dark) | Card header, disabled/readonly input backgrounds |
| Accent (10%) | `blue-600`/`blue-700` (primary button, focus ring) | Reserved for: **primary submit button ("Criar Solicitação")** and **input focus-visible ring** only |
| Destructive | `red-600` (text) | Reserved for: **field validation error text and submit-failure error banner** — no destructive/delete action exists in this create-only form |

Accent reserved for: the single primary submit button and the focus ring on inputs/selects/textarea — never applied to labels, static body text, or the Cancel/Voltar button (which uses `variant="outline"`, neutral border).

### Focal point

- **Create form:** the single-column Card containing the form is the entire page content below the header — there is no wizard/step indicator (unlike `processos/novo`, this is a one-step form matching the backend's single `POST /pareceres/solicitacoes` call). The **primary submit button ("Criar Solicitação")** is the visual and interaction endpoint of the page: it sits at the bottom of the form, styled `bg-blue-600 hover:bg-blue-700 text-white font-bold`, with the neutral "Cancelar" button immediately beside it (outline variant, lower visual weight) — mirrors the button pairing pattern in `processos/novo/page.tsx` step 1 exactly (`Continuar para Conflict Check` + `Voltar`).
- Required fields (`clienteId`, `descricao`) should have their `<Label>` visually identical to optional fields — no asterisk convention exists elsewhere in the codebase (confirmed: `processos/novo/page.tsx` labels have no required-marker styling), so do not introduce one here; rely on inline Zod error text below the field on submit attempt.

Portuguese, sentence case, no exclamation marks, direct tone — matches Phase 65 and `processos/novo/page.tsx` conventions exactly.
