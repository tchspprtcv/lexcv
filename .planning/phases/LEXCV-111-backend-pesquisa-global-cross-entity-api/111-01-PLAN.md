<objective>
Build the data layer for cross-entity global search: one tenant-scoped, accent-folded, exact-match-first native query per entity (Cliente, Processo, Documento, ParecerSolicitacao), plus a migration enabling the two PostgreSQL contrib extensions those queries rely on, plus a Testcontainers integration test that proves — against real PostgreSQL — zero cross-tenant leakage and correct structured-ID-first ranking across all four types.

Purpose: This is the foundation. Per PITFALLS.md Pitfall 1, tenant isolation MUST be built and independently tested at the query layer before any RBAC branching or controller orchestration (Plan 111-02) is layered on top — nothing downstream can be trusted if this layer is wrong. Satisfies SRCH-07 (tenant isolation per sub-query) and SRCH-02 (structured-ID exact/prefix ranked before substring).

Output: 4 new `pesquisarGlobal` repository methods, `111-enable-search-extensions.sql`, and `PesquisaRepositoryIT`.
</objective>
