Create a package-private-usable `final class RecusaTransacional` in `com.lexcv.controllers` with a private constructor and `public static <T> ResponseEntity<T> recusar(ResponseEntity<T> resposta)`. The body calls `TransactionAspectSupport.currentTransactionStatus().setRollbackOnly()` inside a try, catches `org.springframework.transaction.NoTransactionException` and does nothing in that case, then returns `resposta`.

Doc-comment (Portuguese) with the full reasoning, because it is non-obvious:
- Decision 3 requires "refused request → no change, no event".
- Once a handler is `@Transactional`, returning an error ResponseEntity is a NORMAL return, so Spring COMMITS.
- With open-in-view on (Spring Boot default, not overridden in application.yml), an entity loaded by `findById` is managed, so any in-memory mutation made before the refusal (for example `updateUser` calling `setEmail`/`setNome` before a later 403) would be flushed by dirty-checking at that commit. Today, without a transaction, that flush never happens.
- Marking the transaction rollback-only keeps today's behavior. It also makes a caught `DataIntegrityViolationException` (which Spring already flagged as global rollback-only when it crossed the repository proxy) end in a silent rollback instead of `UnexpectedRollbackException`, because `AbstractPlatformTransactionManager.commit` checks local rollback-only before global.
- The `NoTransactionException` catch exists only for unit tests that call handlers directly without a proxy. The presence of `@Transactional` on the seven handlers is asserted separately by reflection (plans 03 and 04).

Test `RecusaTransacionalTest`: build a tiny static nested test bean with two `@Transactional` public methods, `recusa()` (returns `RecusaTransacional.recusar(ResponseEntity.status(409).build())`) and `aceita()` (returns 200). Wrap it with `ProxyFactory` (`setProxyTargetClass(true)`) plus `new TransactionInterceptor((TransactionManager) txManager, new AnnotationTransactionAttributeSource())`. `txManager` is a Mockito mock of `PlatformTransactionManager` whose `getTransaction(any())` returns a new `SimpleTransactionStatus()`. Capture the status passed to `commit` and assert the flags per the behavior bullets. Also call `recusar` directly with no proxy and assert that it returns the same instance without throwing.
