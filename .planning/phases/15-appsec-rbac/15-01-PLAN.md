# Plan 15-01: AppSec & RBAC enforcement

**Phase:** 15
**Goal:** Enforce granular RBAC and add security headers

<steps>
1. **Security Headers Backend:** Update `SecurityConfig.java` to configure Spring Security HTTP headers (CSP, HSTS, X-Frame-Options DENY, X-Content-Type-Options nosniff).
2. **Security Headers Frontend:** Add `headers()` to `next.config.js` for the frontend to emit security headers.
3. **RBAC Enforcement:** Add `@PreAuthorize` annotations on `ResourceController.java` endpoints mapping to the correct permissions (e.g. `clientes:view`, `processos:edit`).
</steps>
