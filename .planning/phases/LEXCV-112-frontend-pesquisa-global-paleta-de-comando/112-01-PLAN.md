<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Phase 111 API response (`titulo`/`subtitulo`/`rota`) → client | The response CONTENT is derived from tenant-user-entered data (cliente names, processo numbers, parecer descricao) — attacker-influenceable text, even though the endpoint is tenant/RBAC-filtered server-side |
| `q` term → outbound request URL | User-typed query is interpolated into the `/pesquisa?q=` URL |
| Recent visits → sessionStorage on a shared institutional workstation | Record identifiers persist in the browser tab session |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-112-01 | Tampering / XSS | highlight-match.tsx rendering server-influenced title/subtitle | mitigate | `highlightMatch` splits the string into React children and wraps only the matched slice in `<strong>` — React auto-escapes all text nodes. It NEVER uses `dangerouslySetInnerHTML`. A cliente named `<img onerror=...>` renders as inert text. Acceptance greps assert zero `dangerouslySetInnerHTML` |
| T-112-02 | Information Disclosure | search-recents on a shared workstation | mitigate | Recents live in `sessionStorage` (per-tab, cleared on tab/browser close), NEVER `localStorage`, and are never transmitted to the server — the confidentiality-driven choice locked in 112-CONTEXT.md / SRCH-10. Acceptance greps assert `localStorage` count 0. Residual risk (a co-worker reusing the same still-open tab session) is accepted as the conservative baseline this design already chose over localStorage |
| T-112-03 | Information Disclosure / injection | useGlobalSearch outbound `q` | mitigate | `encodeURIComponent(termo.trim())` before interpolation; `>= 2` char enabled gate; same-origin `apiFetch` with cookie auth (no bearer token in JS). The server additionally escapes ILIKE metacharacters (Phase 111 WR-02) and caps results |
| T-112-SC | Tampering (supply chain) | package installs | accept (N/A) | Zero new dependencies — all primitives (@tanstack/react-query, react) already in web/package.json. No npm install; package-legitimacy gate does not apply |
</threat_model>
