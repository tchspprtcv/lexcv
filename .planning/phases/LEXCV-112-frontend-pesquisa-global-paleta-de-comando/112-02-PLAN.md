<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| `rota` (server-provided) → `router.push` | The navigation target comes from the API; must be trusted only as an internal path |
| `titulo`/`subtitulo` (server-provided, tenant-user-authored) → React render + highlight | Attacker-influenceable text rendered inside the palette |
| client-side permission check → skeleton display | A display-only optimization that must not be mistaken for the security boundary |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-112-04 | Elevation of Privilege / open-redirect | `navigate(rota)` before router.push | mitigate | **HIGH severity.** `navigate` calls `isInternalLinkUrl(rota)` (the hardened WHATWG-parser guard that already survived two bypass fixes — rejects `//host`, backslash, and control-char variants by resolving to a non-sentinel origin) and returns without navigating if the rota is not an internal path. A malicious `rota` from a compromised/hostile API response cannot drive an off-site redirect. Acceptance greps assert the guard is present |
| T-112-05 | Tampering / XSS | rendering titulo/subtitulo via highlightMatch | mitigate | All result text renders as React children (auto-escaped); `highlightMatch` (Plan 112-01) wraps only the matched slice in `<strong>` and never uses `dangerouslySetInnerHTML`. No raw HTML injection path exists |
| T-112-06 | Tampering (result-integrity) | cmdk re-ranking | mitigate | `<Command shouldFilter={false}>` disables cmdk's fuzzy `command-score`, which otherwise re-sorts or (at score 0) silently HIDES the backend's already-correct exact/prefix>substring ranking — a UI-only integrity bug invisible in the network tab (PITFALLS.md Pitfall 4). Acceptance greps assert the flag |
| T-112-07 | Information Disclosure | permission-gated skeleton groups | mitigate | Skeleton groups render only behind `permissions.isFetched && can.view(scope)` (never `!isLoading`, the recurring race). This is display-only; the authoritative RBAC filter is 100% server-side (Phase 111 gate-before-fetch), so a type the client optimistically skeletons but the server omits simply shows no group. No forbidden data is ever fetched or rendered |
| T-112-SC | Tampering (supply chain) | package installs | accept (N/A) | Zero new dependencies — command/dialog/empty/skeleton/lucide/react-query all already installed (UI-SPEC Registry Safety). No npm install; package-legitimacy gate does not apply |
</threat_model>
