<objective>
Implement the service and endpoint for registering a subscription payment from an office and atomically emitting a LexCV Fatura-Recibo with isolated series numbering and outbox queuing.
</objective>

  <name>Task 1: SubscricaoFaturadaService and DTOs</name>
  <files>
    backend/src/main/java/com/lexcv/services/SubscricaoFaturadaService.java,
    backend/src/main/java/com/lexcv/dtos/RegistarPagamentoSubscricaoRequest.java,
    backend/src/main/java/com/lexcv/dtos/SubscricaoFaturaResponse.java,
    backend/src/test/java/com/lexcv/services/SubscricaoFaturadaServiceTest.java
  </files>
  <action>
    1. Create `RegistarPagamentoSubscricaoRequest` with validations: `tenantId` (UUID, non-null, existing non-LexCV tenant), `valorPago` (> 0), `dataPagamento` (non-null, <= today), `metodo` (non-blank), `periodoInicio` (non-null), `periodoFim` (non-null, >= periodoInicio), `chaveIdempotencia` (UUID).
    2. Create `SubscricaoFaturaResponse` mapping the emitted DocumentoFiscal and PagamentoSubscricao.
    3. Create `SubscricaoFaturadaService` (`@Transactional`):
       - Verifies that LexCV fiscal config is active and complete.
       - Retrieves the subscriber tenant details (nif, nome, morada from tenant or its configuracao_fiscal if present).
       - Locks the platform's active FR series (`SerieFiscal` under LexCV tenantId).
       - Computes next sequence number and formatted number (e.g., `FR-LEXCV 2026/1`).
       - Calculates base and IVA (using standard 15% IVA or exempt based on LexCV regime).
       - Persists `PagamentoSubscricao`.
       - Persists snapshot `DocumentoFiscal` and `DocumentoFiscalLinha` ("Subscrição LexCV - Plano {PLANO} ({PERIODO})").
       - Persists `ComunicacaoFiscal` (initial state PENDENTE) and queues in `FilaComunicacaoFiscal`.
       - Persists `EntregaEmailFiscal` if automatic email is active.
       - Publishes audit event `subscricao_pagamento_faturado`.
    4. Write unit tests in `SubscricaoFaturadaServiceTest`.
  </action>
</task>
