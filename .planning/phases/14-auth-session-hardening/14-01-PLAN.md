# Plan 14-01: Migrar auth storage para HttpOnly Cookies e Rate Limit

**Phase:** 14
**Goal:** Secure authentication flows and session management

<steps>
1. **Password Complexity:** Update `AdminController` (createUser, updateUser) and `AuthController` (changePassword) to validate passwords against a regex: `^(?=.*[a-z])(?=.*[A-Z])(?=.*\d)(?=.*[@$!%*?&])[A-Za-z\d@$!%*?&]{8,}$`.
2. **Rate Limiting:** Implement a simple in-memory rate limiter using `ConcurrentHashMap` inside `AuthController.java` for `/login`. Limit to 5 failed attempts per IP or Email per 15 minutes.
3. **HttpOnly Cookies:** 
   - Modify `AuthController.login()` and `AuthController.refresh()` to return `Set-Cookie` headers using `ResponseCookie`.
   - Add a `CookieFilter` or modify `JwtAuthenticationFilter` to extract the JWT from cookies instead of the `Authorization` header.
</steps>
