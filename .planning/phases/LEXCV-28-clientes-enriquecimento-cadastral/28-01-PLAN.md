## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-28-01 | Tampering | Cliente.java (JPA Constraint) | mitigate | Impor a restrição unique no banco de dados para (tenant_id, documento_numero) prevenindo bypass lógico. |
| T-28-02 | Information Disclosure | ResourceController.java | mitigate | Restringir o acesso a dados de clientes com `@PreAuthorize("hasAuthority('clientes:view')")` para garantir isolamento por tenant. |
| T-28-03 | Spoofing | Zod validator / Controller | mitigate | Validar o formato do NIF dinamicamente no Zod (frontend) e no Controller (backend) prevenindo inserções inválidas. |
| T-28-SC | Tampering | npm/pip/cargo installs | mitigate | slopcheck + blocking human checkpoint para pacotes [ASSUMED]/[SUS] (caso novos pacotes fossem instalados). |
</threat_model>
