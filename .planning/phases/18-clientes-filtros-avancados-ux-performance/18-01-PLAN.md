# Plan 18-01: Clientes — Filtros avançados e UX/Performance

**Phase:** 18
**Goal:** Filtros avançados + pesquisa multi-campo com debounce, e melhorias de UX/performance na listagem de clientes.

<steps>
1. **Contrato de dados (Frontend):** Expandir tipos e requests de `Cliente` e `ClientesListFilters` para suportar `q`, `tipo`, `ativo`, `localidade`, `createdFrom`, `createdTo`.
2. **Hook de Clientes:** Atualizar `useClientes()` para serializar filtros adicionais e garantir cache keys estáveis.
3. **UI de Filtros:** Atualizar a página de listagem de clientes para incluir pesquisa multi-campo com debounce e painel “Avançados” com os novos filtros.
4. **Formulários Cliente:** Atualizar criar/editar para suportar campos de contacto/localidade/morada (alinhado ao contrato).
5. **Backend Clientes:** Atualizar entidade `Cliente` e `GET /clientes` para suportar os novos filtros (incl. data range) e retornar os novos campos.
6. **Mock API (backup):** Atualizar handlers `api-backup/v1/clientes` para suportar filtros e payload estendido.
7. **Verificação:** Validar filtros e consistência UI (incl. debounce e estados).
</steps>
