  <action>
    In use-clientes.ts, add the following hooks after the existing ones. Follow the exact mutation/query patterns already used in the file:

    useUploadProcuracao(clienteId: string):
      useMutation calling apiFetch(`/api/v1/clientes/${clienteId}/procuracao`, { method: "POST", body: formData })
      where formData is FormData passed as mutation variable. Do NOT set Content-Type header.
      onSuccess: invalidateQueries(["clientes", "detail", clienteId])
      Returns mutation with mutate(formData: FormData)

    useDownloadProcuracao():
      useMutation calling apiFetch(`/api/v1/clientes/${clienteId}/procuracao/download`)
      Returns { url: string, expiresIn: number }. Variable is clienteId: string.

    useDeleteProcuracao(clienteId: string):
      useMutation calling apiFetch with DELETE. onSuccess invalidates ["clientes", "detail", clienteId].

    useClienteAdvogados(clienteId: string):
      useQuery({ queryKey: ["clientes", clienteId, "advogados"], queryFn: () => apiFetch(...).then(r => r.json()) })

    useAddAdvogado(clienteId: string):
      useMutation POST /api/v1/clientes/{clienteId}/advogados/{userId}. Variable is userId: string.
      onSuccess invalidates ["clientes", clienteId, "advogados"]

    useRemoveAdvogado(clienteId: string):
      useMutation DELETE /api/v1/clientes/{clienteId}/advogados/{userId}. Variable is userId: string.
      onSuccess invalidates ["clientes", clienteId, "advogados"]

    useClienteAdministrativos(clienteId: string): same pattern as useClienteAdvogados but path is /administrativos
    useAddAdministrativo(clienteId: string): same pattern as useAddAdvogado but path is /administrativos
    useRemoveAdministrativo(clienteId: string): same pattern as useRemoveAdvogado but path is /administrativos

    In schemas/clientes.ts, add to the clienteFormSchema z.object:

        total: z.number().optional(),

        previsao: z.string().trim().optional(),
      }).optional(),

    Also update the exported ClienteFormValues type (it is inferred via z.infer so no change needed — just ensure schema is valid).
