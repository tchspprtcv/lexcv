- Path: GET /api/v1/pareceres/pesquisa (top-level, sibling to /pareceres/solicitacoes — NOT nested)
- Guard: @PreAuthorize("hasAuthority('pareceres:view')")
- Query params (all optional): texto (String), clienteId (UUID), advogadoId (UUID), status (String), dataInicio (LocalDateTime), dataFim (LocalDateTime)
- Response: ParecerSolicitacao[] (identical shape to /pareceres/solicitacoes)

CRITICAL date-format contract: dataInicio/dataFim are Spring @RequestParam LocalDateTime. A bare "YYYY-MM-DD" from <input type="date"> does NOT parse as LocalDateTime — the codebase parses these with DateTimeFormatter.ISO_DATE_TIME elsewhere (ResourceController.java lines 1724/1733), which requires a full date-time string. The hook MUST append a time component before sending: dataInicio → `${date}T00:00:00`, dataFim → `${date}T23:59:59`. Sending the bare date will 400. This overrides the pattern-mapper's "pass the raw date string" note, which was based on the financeiro filter (a different, string-comparison endpoint).

- usePareceres: queryKey ["pareceres","list",...], path /pareceres/solicitacoes, enabled: typeof window !== "undefined", staleTime: 30_000, apiFetch<ParecerSolicitacao[]>
