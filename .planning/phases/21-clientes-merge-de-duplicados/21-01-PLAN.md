# Plan 21-01: Clientes — Merge de duplicados

**Phase:** 21
**Goal:** Merge manual de clientes com reatribuição de relacionamentos e remoção do duplicado.

<steps>
1. **Backend:** Criar endpoint `POST /clientes/merge` que faz: validação tenant, copia campos em falta para o principal, move processos/contactos/notas, remove conta do duplicado e apaga duplicado.
2. **Frontend:** Criar página `/clientes/merge` para seleção (principal + duplicado) e execução do merge, com feedback via toaster.
3. **UI entrypoint:** Adicionar acesso a partir da listagem de clientes (botão “Merge”).
4. **Verificação:** Confirmar que processos/contactos/notas passam para o principal e que o duplicado deixa de existir.
</steps>
