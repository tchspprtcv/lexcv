    ClasspathXsdResolver implements LSResourceResolver: holds BASE "xsd/efatura/" and Set WHITELIST of the 22 manifest paths (e.g. "EnvelopedSignature.xsd", "common/W3C_XMLDSig.xsd"); resolveResource derives the referring directory from baseURI (prefix "classpath:xsd/efatura/"), resolves systemId with java.net.URI.resolve over a synthetic "classpath:/xsd/efatura/<dir>/" base, normalises, strips the prefix, and returns an LSInput (minimal inner class or DOMImplementationLS input) only if the remainder is in WHITELIST and the class loader finds it; any absolute scheme other than the synthetic one -> null. No java.nio.file usage.
    ResultadoValidacao: record (boolean valido, String codigo, int linha, int coluna) with factories valido() / invalido(codigo, linha, coluna); codes "XSD_INVALIDO", "XML_PROIBIDO" (DOCTYPE/entity), "XML_ILEGIVEL". No message text field: the raw parser message is logged at DEBUG only (it can contain names/NIF; V7/V8).
