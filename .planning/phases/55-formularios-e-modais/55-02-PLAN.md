Em cada ficheiro de formulário listado, aplicar as classes de touch target mobile a:

**1. Inputs de texto (`<Input>` components):**
Adicionar `max-sm:h-12 max-sm:text-base` ao className existente de cada Input dentro de formulários.

Exemplos de transformação:
- `<Input id="nome" className="rounded-none" {...form.register("nome")} />`
  → `<Input id="nome" className="rounded-none max-sm:h-12 max-sm:text-base" {...form.register("nome")} />`

- `<Input id="email" {...form.register("email")} />`
  → `<Input id="email" className="max-sm:h-12 max-sm:text-base" {...form.register("email")} />`

Aplicar a TODOS os `<Input>` dentro de `<form>` ou formulários geridos por react-hook-form nos ficheiros listados.

NÃO aplicar a:
- Inputs de pesquisa/filtro em listagens (ex: campo de pesquisa no topo de clientes/page.tsx ou processos/page.tsx) — esses inputs não fazem parte de formulários de criação/edição
- `<Textarea>` components — têm altura natural própria
- `<Select>` components — têm comportamento nativo no mobile

**2. Botões de submit (`<Button type="submit">`):**
Adicionar `max-sm:min-h-[48px]` ao className existente de cada botão de submit.

Exemplos de transformação:
- `<Button type="submit" disabled={isSubmitting}>Guardar</Button>`
  → `<Button type="submit" disabled={isSubmitting} className="max-sm:min-h-[48px]">Guardar</Button>`

- `<Button type="submit" className="w-full" disabled={isSubmitting}>Criar Cliente</Button>`
  → `<Button type="submit" className="w-full max-sm:min-h-[48px]" disabled={isSubmitting}>Criar Cliente</Button>`

Aplicar APENAS a `type="submit"` — não a botões de cancelar, voltar ou ícones.

NÃO modificar:
- `web/src/components/ui/input.tsx` — primitivo base
- `web/src/components/ui/button.tsx` — primitivo base
- Inputs de pesquisa/filtro fora de formulários de criação/edição
- Botões que não são `type="submit"`

Para os dialogs de formulário em `financeiro/[id]/page.tsx` e `processos/[id]/page.tsx`, aplicar FORM-03 também aos inputs e botões de submit DENTRO dos dialogs (o Task 1 já trata do container dialog; este task trata dos campos internos).
