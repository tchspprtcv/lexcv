| T-50-05 | Information Disclosure | Cross-tenant document access | mitigate | doc.getTenantId().equals(getTenantId()) check precedes every StorageService call; object key prefix tenantId is defence-in-depth |
| T-50-06 | Elevation of Privilege | upload without auth | mitigate | Existing @PreAuthorize("hasAuthority('documentos:create')") on upload endpoint preserved — not touched by this refactor |
| T-50-07 | Denial of Service | MinIO unreachable on upload/download/delete | mitigate | StorageUnavailableException caught at each endpoint; returns 503 with clear message instead of 500 |
