# Phase 133 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

Scope: one new tab "Faturação" in Definições (`web/src/app/(dashboard)/settings/page.tsx`), implemented as a new component `web/src/app/(dashboard)/settings/faturacao-tab.tsx` (same pattern as `auditoria-tab.tsx`), plus a hook `web/src/hooks/use-faturacao.ts` (TanStack Query over `apiFetch`). No new visual language: reuse existing primitives, tokens and patterns. Sources: 133-CONTEXT.md (locked decisions), `auditoria-tab.tsx`, `globals.css`, `components.json`.

## Spacing Scale

Declared values (multiples of 4), using the Tailwind scale already in use:

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Gap label-to-hint, icon-to-text inside badges |
| sm | 8px | `space-y-2` between Label, Input and helper/error text; button icon gap |
| md | 16px | `gap-4` between form fields in the grid; Card content padding rhythm |
| lg | 24px | `space-y-6` between Cards / blocks of the tab (same as `auditoria-tab`) |
| xl | 32px | not used in this tab |
| 2xl | 48px | not used in this tab |
| 3xl | 64px | not used in this tab |

Exceptions: Input and Button heights follow the existing primitives (h-10 inputs, matching `auditoria-tab` select). Table rows use the `table.tsx` default cell padding. Dialog internal spacing is the `alert-dialog.tsx` default. No custom pixel values.

Layout: tab root is `<div className="space-y-6">`. Form fields use `grid gap-4 sm:grid-cols-2`; fields marked full-width use `sm:col-span-2` (Firma, Morada). Single column below `sm`.

| Role | Value | Usage |

Status badge (Badge primitive):

- "Faturação desligada": `variant="outline"`

## Screen Structure (Faturação tab)

Tab trigger: added after "Auditoria", rendered only if `hasScopedPermission(perms, "financeiro", "manage")` (use `can.manage("financeiro")`, same as `hasRbacManage` pattern). Markup copied verbatim from the existing tab buttons, icon `Receipt` (lucide) at `h-4 w-4`, label "Faturação". Add `"faturacao"` to `TabId`. Panel wrapper: `<div className="animate-in fade-in duration-200"><FaturacaoTab /></div>`. If a user lacking the permission somehow reaches the tab, show the existing `AccessDeniedState` (`components/shared/access-denied-state`) instead of the form.

Order of blocks inside `<div className="space-y-6">`:

1. Header: `h2.text-xl.font-semibold` "Faturação" + `p.text-sm.text-slate-500` description + status Badge aligned right (`flex items-start justify-between gap-4`).
2. Simulation notice (always visible, see Color).
3. Card "Dados fiscais do escritório" — form.
4. Card "Ativação da faturação" — status text + Activate/Deactivate button.
5. Card "Envio automático por email" — Switch row (disabled unless faturação is active).
6. Card "Séries de numeração" — read-only table.

### Block 3 — Dados fiscais form (react-hook-form + Zod schema in `web/src/schemas/`)

| Field | Control | Rules |
|-------|---------|-------|
| NIF | `Input` inputMode numeric, maxLength 9, `font-mono` | 9 digits, first digit 1–9; locked (disabled + `Lock` icon + helper) once a series has `ultimoNumero > 0` |
| Firma | `Input`, full width | required |
| Morada | `Input`, full width | required, max 100 chars; helper shows "{n}/100" |
| Localidade | `Input` | required |
| País | `Input` disabled, value "Cabo Verde" | fixed, not submitted as editable |
| Email de contacto | `Input type=email` | required, valid email |
| Telefone de contacto | `Input type=tel` | required |
| Regime de IVA | select (`native-select`) options "Normal" / "Isento" | required |
| Motivo de isenção | select, 21 `TaxExemptionReasonCode` options labelled in PT ("{código} — {rótulo PT}") | visible and required only when regime = Isento; clears when switching back to Normal |

Interaction: validation on blur and on submit (zod resolver, `mode: "onTouched"`). Errors rendered under the field as `text-sm text-red-600` with `aria-describedby`, input gets `aria-invalid`. Footer row: right-aligned `Button` "Guardar dados fiscais", disabled while pristine or submitting (label becomes "A guardar..."). Success: sonner toast "Dados fiscais guardados." Server 4xx field errors map to the field; others are toasted by `apiFetch`.

### Block 4 — Ativação

- Faturação desligada: text "A faturação está desligada. Os pagamentos continuam a ser registados como até agora, sem documento fiscal." + primary Button "Ativar faturação". If fiscal data is incomplete or form is dirty/unsaved: button disabled with helper "Preencha e guarde os dados fiscais para ativar a faturação."
- Faturação ativa, sem documentos emitidos (todas as séries com `ultimoNumero` 0 ou sem séries): text "A faturação está ativa." + outline Button "Desativar faturação" (opens destructive AlertDialog).
- Faturação ativa, com documentos emitidos: text "A faturação está ativa e não pode ser desligada porque já foram emitidos documentos." + no deactivate button (do not show a disabled destructive button; the explanation replaces it).

Activate dialog (`AlertDialog`): title, description (2 short paragraphs), Cancel + confirm. Confirm button primary. While request is pending, both buttons disabled, confirm label "A ativar...". On 409/422 from backend (incomplete data): dialog closes, inline error `text-red-600` in the Card, copy below. Dialog stays open on network failure (same pattern as page.tsx:1068).

Deactivate dialog (`AlertDialog`): confirm button uses `variant="destructive"`, cancel is default-focused.

### Block 5 — Envio automático por email

Row: left `Label` (htmlFor switch id) "Enviar faturas por email ao cliente" with helper `text-sm text-slate-500`; right `Switch`. Default OFF. Disabled with Tooltip/helper when faturação is not active.
- Turning ON: Switch does NOT change optimistically. It opens `AlertDialog` with a required `Checkbox` "Compreendo que os documentos simulados não têm validade fiscal". Confirm button "Ligar envio automático" disabled until the checkbox is checked; checkbox resets each time the dialog opens. On success the switch shows ON, and below it a `text-xs text-slate-500` line "Aceite por {nome} em {data}" (date via `toLocaleString("pt-CV")`, same helper as auditoria-tab).
- Turning OFF: immediate (no dialog), toast "Envio automático desligado."; no acknowledgement required.
- Escape/overlay click/Cancel closes the dialog without change.

### Block 6 — Séries (read-only)

`Table` with columns: Tipo (label PT, e.g. "Fatura-Recibo"), Ano, Código (`font-mono`), Último número (right-aligned, tabular-nums). Optional trailing column Ambiente with outline Badge "Simulado". Sorted by ano desc then tipo. No row actions, no buttons, no inputs (read-only guarantee as in auditoria-tab). Series are created by the system; no create/edit UI.

States for each data block (inside its Card, never replacing the whole tab, per auditoria-tab):
- Loading: `Skeleton` rows (form: 4 skeleton inputs; table: 3 skeleton rows) or text "A carregar..." (`text-sm text-slate-500`, existing pattern).
- Error: `text-sm text-red-600` message from the copy table.
- Empty series: `Empty` component.

Accessibility: every control has a `Label`; dialogs are Radix AlertDialog (focus trap, Esc); Switch has an accessible name; error text linked via `aria-describedby`; keyboard: tab order follows visual order; touch targets >= 40px (existing control heights). Contrast: reuse slate-500 on white (as existing tabs). Dark mode: all classes paired with `dark:` variants as in existing code.

Responsive: single column below 640px; table wrapped in `overflow-x-auto`; header status badge wraps below the title.

## Decisions Made Without CONTEXT.md (defaults, consistent with codebase)

- Tab visibility uses `can.manage("financeiro")` (equivalent to `hasScopedPermission(perms, "financeiro", "manage")`).

- Deactivate button hidden (replaced by explanatory text) when documents exist, rather than shown disabled.

- Series "Ambiente" column shown as outline Badge "Simulado"; omit column if backend returns only simulated series and planner prefers minimal table.
- Typography reuses the 12/14/20px, 400/600 set already used by the Settings tabs.
