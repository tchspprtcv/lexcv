## Trust Boundaries

| URL directa → /clientes/{id}/ficha | Utilizador autenticado mas sem clientes:view pode tentar aceder directamente à URL |
| Nova aba → API /api/v1/clientes/{id} | Cookie de sessão segue na nova aba (mesmo domínio, credentials: "include") — acesso à API controlado pelo backend |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-60-02 | Information Disclosure | Dados do cliente em nova aba | accept | Cookie httpOnly segue na nova aba (mesmo domínio); backend valida sessão em cada request; sem risco adicional vs. página de detalhe normal |
