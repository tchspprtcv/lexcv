## Trust Boundaries

| Boundary | Description |
|----------|--------------|
| Client → `POST /processos/{id}/decisoes` (multipart) | Untrusted file upload + form fields; `processoId` is taken from the tenant-checked path variable, never from a client-supplied form field, closing the vector PITFALLS.md Pitfall 7 warns about for the *creation* path |
| Client → `PUT`/`DELETE /processos/{id}/decisoes\|testemunhas/{childId}` | Untrusted path variables; `id` (processo) and `{childId}` (Decisão/Testemunha) are independently supplied and must both be validated — a same-tenant user could otherwise guess/enumerate a sequential `Integer` child id belonging to a *different* processo they don't have the URL for |
