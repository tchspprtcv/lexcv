<objective>
Fazer nascer o mecanismo central do marco: provisionar um escritório novo instancia-lhe uma cópia própria de cada molde actual, dentro da mesma transacção que cria o Tenant e o utilizador ADMIN inicial.

Purpose: este é o caminho de menor risco para provar o mecanismo de instanciação (um escritório que ainda não existe não tem nada a perder), antes de a Phase 126 o reutilizar para migrar escritórios reais. A invariante de snapshot é provada aqui, por teste — é dela que depende todo o aviso de não-propagação que a consola vai mostrar.
Output: `provisionTenant` estendido, 1 classe de teste nova, 1 teste existente actualizado.

**Fronteira intransponível:** o utilizador ADMIN inicial continua a receber o papel **GLOBAL** `ADMIN` (`Set.of(adminRole)`, inalterado). Não trocar para o papel instanciado — isso criaria dois caminhos de resolução de autoridade em simultâneo, precisamente o que a Phase 126 existe para eliminar de uma vez. Os papéis instanciados nascem DORMENTES.
</objective>
