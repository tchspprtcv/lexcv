# Plan 20-01: Clientes — Import/Export (CSV)

**Phase:** 20
**Goal:** Exportar/importar clientes via CSV simples com validação e feedback no UI.

<steps>
1. **CSV utilitário:** Implementar serialização (export) e parsing (import) para CSV simples.
2. **Export UI:** Adicionar botão “Exportar CSV” na listagem de clientes, gerando ficheiro com os dados filtrados.
3. **Import UI:** Adicionar botão “Importar CSV”, com upload de ficheiro, parsing + validação e criação em lote (com relatório de sucesso/erro).
4. **Backend:** Reutilizar `POST /clientes` para import em lote (sem endpoint dedicado nesta fase).
5. **Verificação:** Confirmar que export respeita filtros e que import dá feedback claro (incl. linhas inválidas).
</steps>
