<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser (per-role) ← RBAC-gated row actions | The Clientes Ações column exposes edit/delete affordances that are UI-layer expressions of backend authorization; a careless port could show an action to a role that shouldn't have it |
| DataTable ← already-fetched, already-server-filtered array | Sorting/pagination happen client-side over data the use-* hook already fetched (tenant-scoped, server-filtered) — no new fetch, no new exposure |

| T-104-03-ID | Information Disclosure | client-side sort/paginate | accept | Data already fully fetched + server-filtered by useClientes/useProcessos; no getFilteredRowModel duplicates the server's authorization-aware filter |
