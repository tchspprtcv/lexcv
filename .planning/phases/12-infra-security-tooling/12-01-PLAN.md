# Plan 12-01: Configurar .env, profiles e plugins de segurança no Maven/npm

**Phase:** 12
**Goal:** Fix risky configs, secure secrets, and enable security scanning

<steps>
1. **Backend Config Update**: Modificar `backend/src/main/resources/application.yml` e `application-prod.yml` para remover segredos (JWT secret e DB password) e referenciar variáveis de ambiente.
2. **Spring Security Config**: Desativar `include-message: always` e configurar `ddl-auto: validate` para produção.
3. **Tooling - Backend**: Adicionar o plugin `spotbugs-maven-plugin` e `findsecbugs-plugin` no `backend/pom.xml`.
4. **Tooling - Dependency Check**: Adicionar `dependency-check-maven` no `backend/pom.xml` para SCA.
5. **Tooling - Frontend**: Adicionar script de `npm audit` no `package.json` do frontend, se aplicável, e configurar ESLint com `eslint-plugin-security`.
</steps>
