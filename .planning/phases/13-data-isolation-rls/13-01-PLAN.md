# Plan 13-01: Refatorar repositories e endpoints para isolamento de tenant

**Phase:** 13
**Goal:** Prevent cross-tenant data leakage and implement Row-Level Security

<steps>
1. **Repository Layer:** Modify `ParteRepository`, `FaseRepository`, `MovimentacaoRepository`, `HonorarioRepository`, and `PagamentoRepository` to require `tenantId` in queries (`findByProcessoIdAndTenantId`, etc.).
2. **Controller Layer:** Update the respective REST endpoints to pass the authenticated user's `tenantId` to the service/repository layer for data access and mutations.
3. **Admin Controller Isolation:** Update `AdminController` so that an Admin can only view, create, or modify users that belong to their own `tenantId`.
4. **Hibernate Filter (Optional but recommended):** Add `@FilterDef` and `@Filter` for `tenant_id` on the core entities as a safety net against missing queries.
</steps>
