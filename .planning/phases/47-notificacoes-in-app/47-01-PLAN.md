  <action>
    Adicionar o método `getUpcomingEventos` imediatamente após o método `listEventos` (depois da linha que retorna `ResponseEntity.ok(eventos)` do listEventos, antes do bloco `@GetMapping("/eventos/{id}")`).

    Anotações e assinatura:
    - `@PreAuthorize("hasAuthority('agenda:view')")`
    - `@GetMapping("/eventos/upcoming")`
    - `public ResponseEntity<?> getUpcomingEventos(@RequestParam(defaultValue = "7") int days)`

    Validação: se `days <= 0`, retornar `ResponseEntity.status(HttpStatus.BAD_REQUEST).body(Map.of("message", "O parâmetro 'days' deve ser maior que zero"))`.

    Lógica (seguir o mesmo padrão in-memory de listEventos — NÃO introduzir JPQL ou novo repositório):
    1. `UUID tenantId = getTenantId();`
    2. `List<Evento> eventos = eventoRepository.findByTenantId(tenantId);`
    3. `LocalDateTime now = LocalDateTime.now();`
    4. `LocalDateTime limit = now.plusDays(days);`
    5. Remover os concluídos: `eventos.removeIf(e -> Boolean.TRUE.equals(e.getConcluido()));`
    6. Remover fora da janela: `eventos.removeIf(e -> e.getDataInicio() == null || e.getDataInicio().isBefore(now) || e.getDataInicio().isAfter(limit));`
    7. Ordenar: `eventos.sort(Comparator.comparing(Evento::getDataInicio));`
    8. Limitar a 10: `List<Evento> slice = eventos.size() > 10 ? eventos.subList(0, 10) : eventos;`
    9. Mapear para slim DTO — usar um record anónimo via `Map.of` por item, ou criar um `java.util.stream` com `map()`. Campos da resposta: `id`, `titulo`, `dataInicio` (String ISO-8601 via `.toString()`), `processoId` (String via `.toString()` se não null, caso contrário null), `tipo`.
       Exemplo de stream:
       `slice.stream().map(e -> Map.of("id", e.getId(), "titulo", e.getTitulo(), "dataInicio", e.getDataInicio().toString(), "processoId", e.getProcessoId() != null ? e.getProcessoId().toString() : "", "tipo", e.getTipo() != null ? e.getTipo() : "")).toList()`
       Note: `Map.of` não aceita valores null — use string vazia `""` como fallback para `processoId` e `tipo` nullable.
    10. Retornar `ResponseEntity.ok(slimList)`.

    Não alterar nenhum outro método. Não introduzir imports novos além dos já presentes (`LocalDateTime`, `Comparator`, `List`, `Map`, `UUID` já estão importados no ficheiro).
