Adicionar ao final dos campos da classe `Honorario` (antes do fecho da classe):

1. Adicionar import `org.hibernate.annotations.Formula` no topo do ficheiro (a seguir aos imports existentes).
2. Adicionar o campo com anotações:

```
@Transient é ERRADO aqui — @Formula é carregado pelo Hibernate, não deve ser @Transient.
```

Usar APENAS `@Formula` (sem `@Transient`) — o Hibernate preenche campos `@Formula` durante o carregamento da entidade. Declarar como:

```
@Formula("(SELECT COALESCE(SUM(p.valor_pago), 0) FROM t_pagamento p WHERE p.honorario_id = id)")
@Column(insertable = false, updatable = false)
private java.math.BigDecimal totalPago;
```

Nota: `@Formula` implica que o campo não é mapeado para uma coluna real — NÃO adicionar `@Column`. Usar apenas a anotação `@Formula`. A assinatura correcta é:

```java
@Formula("(SELECT COALESCE(SUM(p.valor_pago), 0) FROM t_pagamento p WHERE p.honorario_id = id)")
private BigDecimal totalPago;
```

O import necessário: `import org.hibernate.annotations.Formula;`

Não alterar `HonorarioCreateRequest` nem `HonorarioUpdateRequest` (esses não existem como classes separadas — o backend usa a entidade directamente no `@RequestBody` de POST/PUT). O campo `totalPago` é read-only: Hibernate calcula via SQL, Jackson serializa para JSON, mas como não há setter no `@RequestBody` que o use, fica ignorado na escrita. Adicionar `@JsonProperty(access = JsonProperty.Access.READ_ONLY)` ao campo para deixar claro que é somente leitura — import: `import com.fasterxml.jackson.annotation.JsonProperty;`

Verificar que a classe mantém `@Getter @Setter` do Lombok (que gera getter/setter para `totalPago` automaticamente).
