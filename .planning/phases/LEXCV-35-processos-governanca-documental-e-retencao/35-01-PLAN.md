# Phase 35: Processos - Governanca Documental e Retencao

Este plano detalha a implementação das features de governança documental, incluindo classificação (categorias), gestão de versões, níveis de confidencialidade, política de retenção calculada e proteção de apagamento (*legal hold*).

## User Review Required

> [!IMPORTANT]
> A substituição de versão incrementará o valor de `versao` no backend e substituirá o caminho de ficheiro do `Documento` existente. O ficheiro antigo será descartado (o histórico de versões anteriores não será visível nem acessível no MVP para minimizar a complexidade do UI). O utilizador confirma esta simplificação?

> [!WARNING]
> O *Legal Hold* protegerá todos os documentos de um processo contra apagamento (soft/hard delete). Quaisquer chamadas à API para `DELETE /api/v1/documentos/{id}` num processo onde `legalHold = true` devolverão erro de "Operação Bloqueada", com feedback claro no Toaster do frontend.
